# （仮）出張専門博多メンズエステ KAREN — 公式サイト

福岡市博多を中心に展開する出張型リラクゼーションマッサージ店「KAREN」の公式サイト。
静的サイト（HTML / CSS / JS、フレームワークなし）として構築し、GitHub Pages でホスティングする。

> **現在のステータス**: トップページ（`index.html`）の構造・CSS実装が完了。
> 他ページ（コース・料金／セラピスト紹介／出張対応エリア／FAQ／お問い合わせ／特商法・利用規約）は未着手。

## コンセプト

- **店名**: （仮）出張専門博多メンズエステ KAREN
- **サービス**: 出張型のリラクゼーションマッサージ（非性的施術のみ）
- **対応エリア**: 福岡市博多を中心とした福岡市内中心部

## デザイントーン（合意事項）

- **配色**: ベースは白（オフホワイト `#fbf8f6`）。ロゴ・見出し・アクセントに大人向けの
  落ち着いたローズピンク（`#b85c72` / hover `#95465b`）。和の差し色として細線にのみ
  ゴールド（`#b6975f`）を使用。
- **フォント**: `コーポレート明朝 ver2` を第一候補に指定（`css/style.css` の `--font-serif` 参照）。
  この書体は有償の商用フォントのため、フォント本体はリポジトリに含めていない。
  実運用時は Adobe Fonts / MORISAWA PASSPORT / FONTWORKS LETS 等、契約済みの配信方法で
  `<head>` に埋め込みタグを追加すること。未読込時は Google Fonts の `Shippori Mincho` /
  `Noto Serif JP` にフォールバックする。
- **雰囲気**: 派手さより清潔感・信頼感を優先。過度に性的な訴求・身体的スペック表記は行わない。

## ヒーロースライド

- スライド枚数: 2枚
- 切り替え方式: フェード（`opacity` トランジション、6秒間隔で自動切替）
- インジケーター: 無し
- 画像は `images/hero/slide-0{1,2}.svg` の仮プレースホルダー。実写に差し替える際は
  同じファイル名の `.jpg` 等に置き換え、`index.html` 側の `src` を更新する。

## 技術要件

- フレームワーク不使用の静的サイト（HTML / CSS / JS）
- レスポンシブ対応（859px をブレークポイントにハンバーガーナビへ切り替え）
- 画像はSVGのダミープレースホルダー
- GitHub Pages でのデプロイを前提としたルート直下構成

## ローカルプレビュー

```
python3 -m http.server 8000
```

を実行し、`http://localhost:8000/` を開く。

## デプロイ

GitHub リポジトリの Settings → Pages で `main` ブランチのルートを Pages のソースに指定する。
カスタムドメインは `mensesthe-delivery-karen.com`（ルートの `CNAME` ファイルで設定済み）。
ドメイン側のDNSに以下のAレコードを設定し、GitHub側の Settings → Pages で
「Enforce HTTPS」を有効化すること。

```

185.199.109.153
185.199.110.153
185.199.111.153
```
